这个主题只做一件事：让一篇长文从第一行读到最后一行不费劲。

没有卡片，没有阴影，没有渐变，也没有一个需要你点开的弹窗。整站只有三种颜色：钢板灰做底，铁黑做字，朱红做印。朱红在绝大多数页面里只出现两次——左栏那个印章，和当前所在的位置。

## 它长什么样

左边是一条 320px 的固定栏，放着站名、印章、年份索引和页面入口。右边是正文，宽度 768px，16px 字号下正好 48 个汉字一行。

窄到这个程度是有代价的：一屏放不下太多东西。换来的是一篇文章从头到尾不需要左右摇头。

> 排版的目标不是把空间填满，是让眼睛少做无用功。

## 结构

站点只有四种页面：

| 页面 | 路径                   | 作用                         |
| ---- | ---------------------- | ---------------------------- |
| 存档 | `/`                    | 首页就是全部文章，按年份分组 |
| 文章 | `/posts/[slug]`        | 正文 + 左栏目录 + 阅读进度   |
| 标签 | `/tags`、`/tags/[tag]` | 按主题找文章                 |
| 搜索 | `/search`              | 标题、标签、摘要的本地搜索   |

静态页面直接放进 `src/content/pages/`，文件名就是路径。

## 改哪里

颜色、字体、宽度、圆角、动效时长全在 `src/styles/global.css` 的 `:root` 里：

```css
:root {
  --color-ground: #eeede9; /* 钢板底 */
  --color-ink: #26282b; /* 铁黑字 */
  --color-seal: #b23a2e; /* 朱红印 */

  --shell-max: 75rem; /* 页面总宽 */
  --rail-w: 320px; /* 左栏宽 */
}
```

站点名、作者、导航在 `src/config.ts`，两个文件就能换掉整站的身份。

## 它是怎么长出来的

这套样式不是一次设计出来的，是拿一个写了二十年的博客当试验田，一轮轮评审、量尺寸、改数字磨出来的。所以里面有很多看起来莫名其妙的数字，旁边都写着为什么——比如为什么圆角只有一种，为什么字号只有十二档，为什么行宽是 48 而不是更常见的 36。

那些注释不用删，它们是这个主题最值钱的部分。
